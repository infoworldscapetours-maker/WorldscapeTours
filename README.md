## Publish on GitHub Pages
1. Extract this ZIP.
2. Create/open your GitHub repository.
3. Upload every file and the `assets` folder directly to the repository root.
4. Go to **Settings → Pages**.
5. Choose **Deploy from a branch**.
6. Select `main` and `/(root)`.
7. Save.

No build process is required.

## Local preview
Extract the ZIP and open `index.html`. The logo and website photography are bundled locally, so the main visual design does not depend on external image URLs.
